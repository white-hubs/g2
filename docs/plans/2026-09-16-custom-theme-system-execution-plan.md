## 1. 目标与边界

在 G2 主应用中支持内置及自定义主题。主题由主应用集中定义并写入语义化 CSS Token；同 document 的模块联邦子应用天然继承，图表/Canvas/iframe 通过契约事件补充同步。

首个可交付版本（MVP）覆盖：

- 亮/暗内置主题与主色自定义；
- `pc-chrome`、`pc-ui`；
- 安防监控与通用设备监控页库试点；
- 本地持久化、实时切换、自动化校验。
- 主题控制台中的本地自定义主题：新建、编辑、删除、即时预览与恢复。

以下范围不进入 MVP：服务端用户/租户主题 CRUD、iframe 完整主题桥接、全领域颜色迁移。它们分别在 P5、P6 完成。
