Counting rules

统计边界：哪些没有算作“已迁子应用”

PC Shell 已迁，但不是子应用

legacy/bimops-fe-web-migrate 已演进为 apps/shells/pc，它属于主应用迁移，不进入 79 个子应用的完成数。

POC Domain 不计迁移完成

poc-inline-pc 和 poc-remote-pc 是架构验证包，并非从旧业务子应用迁入。

Client/Platform 不等于 UI 子应用

例如 alarm-center、device-center 已有 Client 或 Platform，只说明接口/平台能力已迁，不能据此认定对应业务 UI 已迁。

Evidence chain

结论依据

  • 旧门户默认清单 ghcloud/legacy/bimops-fe-web-migrate/public/config.js：79 条有效 microApps 注册。
  • g2 已迁过滤表 apps/shells/pc/src/filter-migrated-qiankun-apps.ts：明确剔除 access-control 和 genericEquipmentMonitor 别名。
  • g2 生产组装清单 deploy/compositions/prod.pc.yaml：正式业务 remote 只有 accessControl；GEM 位于 pageLibrary 槽位。
  • 迁移架构决策 ADR-0023 确认 access-control 为首个真实迁入域；ADR-0059 确认 GEM 转为页面库。
  • 临时兼容桥 ADR-0031：未迁业务应用继续使用旧 window.config.microApps 和 qiankun 生命周期。
  • 排除项 g2 的 POC Domain、服务 Client、Platform、主 Shell 均按职责排除，不用于抬高业务子应用迁移数。
