# 与旧站长期双轨平行；不在主规划钉死灰度切流单位

迁域后的流量策略以 **新仓与旧站（bimops/admin 等）平行并存** 为主，主规划阶段**不钉**「按 Profile / 按域 flag / 整站切换」等灰度切流单位与机制。标准波次负责把域与平台迁入新仓并具备可运行能力；何时、如何把用户从旧站导到新门面，留待必要时机另立专项。对难以纳入标准域契约/组装模型的 **兼容类应用**，同样在必要时立专项处理，不强迫塞进常规迁域 checklist。若日后专项需要清单驱动导流，再单独立项，可复用 Composition Profile，但不预设为本阶段交付物。

**与 ADR-0024 的关系**：ADR-0024 迁域波次顺序第 4 步提及门户域迁入阶段，该步骤仅描述迁域动作本身（域迁入 apps/domains/\* 并具备可运行能力），不构成对本 ADR「不钉灰度切流单位」的例外或修订——切流单位与机制统一以本 ADR 为准。
