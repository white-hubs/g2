# 域契约骨架期仅 routes + 可选 install

`@g2-composition/contract` 在骨架期冻结的域对外入口为：**`routes`（必选）** 与 **`install`（可选）**。夹具域与后续业务域均按此实现 Federation/契约导出。不在同阶段扩展菜单贡献、权限码聚合等门户终态能力——待迁真实域时再演进契约，避免 PoC 被门户完备性拖垮。禁止壳内硬编码绕过契约装夹具。

**后续变更**：真实业务域迁移专项启动后，本条「不扩展菜单贡献」的边界已被 ADR-0036 收紧重开——域契约新增可选 `menuContribution`。骨架期本身冻结的 `routes`/`install` 两个入口不变。
